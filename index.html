System Architecture

Five modular subsystems working together on a single 4-layer PCB.

ASIC Miner BM1366

The Bitmain BM1366 SHA-256 hashing engine. Multiple power domains (VDD core, VDDIO 0.8V/1.8V), UART interface for work distribution, and on-chip nonce rolling for efficiency. This is the same silicon found in industrial miners.

Microcontroller ESP32-S3

Dual-core 240MHz ESP32-S3 with WiFi. Connects to your mining pool over the network, distributes work to the ASIC via UART, and controls power/thermal via I2C. Programming over USB-C — no external tools needed.

Power Delivery TPS40305

A digitally-controlled buck converter steps down 5V to the ASIC core voltage. A DS4432U+ current DAC allows the ESP32 to adjust voltage over I2C for software autotuning. An INA260 power monitor tracks real-time watts.

Thermal Management EMC2101

Closed-loop fan control via the EMC2101 I2C thermal controller. A remote temperature sensor is placed near the ASIC die. PWM fan speed is adjusted automatically to maintain safe operating temperatures.

User Interface SSD1306

A 0.91" OLED display shows live hashrate, temperature, power consumption, and pool status. Physical button for basic interaction. All status is also available via a built-in web dashboard over WiFi.

Voltage Autotuning DS4432U+

The current DAC adjusts ASIC core voltage from 0.04V to 2.4V in fine increments over I2C. Combined with the INA260 power monitor, the firmware finds the optimal voltage/frequency point for maximum efficiency.

Why Bitaxe?

The only fully open-source Bitcoin ASIC miner you can actually build yourself.

Fully Standalone

Connects directly to your mining pool over WiFi. No host computer, no Raspberry Pi, no controller box. Just plug in 5V power and go.

Real ASIC Performance

The BM1366 is a production SHA-256 ASIC from Bitmain, not a hobbyist chip. You get real hashrate in a tiny form factor.

Software Autotuning

Digitally adjustable core voltage + real-time power monitoring = the firmware automatically finds the sweet spot for efficiency.

Thermal Protection

Closed-loop fan control with a temperature sensor right next to the ASIC. Automatically throttles to prevent overheating.

USB-C Programming

Flash new firmware over USB-C. No JTAG programmer or special cables needed. Community firmware (ESP-Miner) is actively maintained.

100% Open Source

KiCad schematics, PCB layout, BOM, gerbers, and 3D models are all public under the CERN-OHL-S license. Build it, modify it, sell it.

Built-in Web Dashboard

Access a web interface over WiFi to monitor hashrate, temperature, power draw, shares found, and pool status in real time.

DIY Friendly

Designed for toaster-oven reflow soldering. Order PCBs and parts yourself, or buy a pre-assembled unit from community vendors.

Technical Specifications

Everything that makes the Bitaxe Ultra tick.

Component Details
Mining ASIC Bitmain BM1366, SHA-256, on-chip nonce rolling
Controller ESP32-S3-WROOM-1, dual-core 240MHz, WiFi 802.11 b/g/n, BLE 5.0
Power Input 5V DC via barrel jack (5.5x2.1mm, center positive) or USB-C
Power Draw ~15W typical (5V @ 3A)
Buck Converter TPS40305 synchronous controller with CSD17311Q5 MOSFETs
Voltage Control DS4432U+ I2C current DAC (0.04V – 2.4V adjustable)
Power Monitor INA260 with integrated 2mΩ shunt, I2C interface
Fan Controller EMC2101 I2C, remote temp sense, 4-pin PWM fan header
Display 0.91" SSD1306 OLED, 128x32, I2C
PCB 4-layer, 6mil trace/space, 1oz outer / 0.5oz inner copper
Programming USB-C (built-in), SPI/JTAG debug header
License CERN-OHL-S v2 (strongly reciprocal open hardware)
Hardware Revision v204 (December 2023)
